# モーション差分（歩行・飛行など連番コマ）の作り方

## 🚫 絶対禁止 — 1枚ずつ独立生成すること

同じポーズを指定しても、**コマ間で形・色・ディテールが必ず揺れる**。
再生すると動きが崩れて使い物にならない。

これは推測ではなく**2回やらかした実績**:
- ぴよ氏の冒険 1.367 で発生 → 1.368 で Veo に作り直し
- その後、非推奨ツールを焼き直して**同じ失敗を再発**させ、12枚分のクレジットを無駄にした

**生成に着手する前に自問する: 「これはモーション差分か？ なら動画方式か？」**
独立コマ生成に着手しそうになったら**即停止**。

## 正しい手順

```
① デザイン確定の立ち絵を1枚だけ生成（静止画）
      ↓
② それを種画像に Veo で「その場モーション」動画を **1キャラ1本**
   （緑背景・カメラ固定・その場で足踏み）
      ↓
③ ffmpeg で全コマ抽出
      ↓
④ コンタクトシートを作って、使うコマをユーザーに選んでもらう
      ↓
⑤ クロマキー → 基準bboxへ整列 → commit
```

ぴよ氏の冒険での実装:

```bash
zsh -ic 'cd <repo>/tools && node veo-<name>-walk.mjs'
ffmpeg -i _raw/<name>.mp4 _raw/veo_frames_<name>/f_%03d.png
node tools/contact-sheet.mjs …                       # 一覧にして見せる
node veo-frames-to-<name>.mjs --frames=a,b,c,d --commit
```

⚠`tools/_raw` は gitignore（mp4 とフレームはコミットしない）。

## 🚫 Veo は1本ずつ。見せてから次を撮る

**動画を生成したら、必ず結果一覧（コンタクトシート＋拡大＋最終サイズのプレビュー）を
ユーザーに見せて判断を仰いでから次を撮る。**

確認なしで2本続けて生成し、3本目に着手しかけて叱られた前例がある（2026-07-23）。

**NG/OK の最終判定はユーザーがする。** Claude の検品は「見せる候補を準備する」ことであって、
**OKテイクを勝手に落としてよい免罪符ではない。**

## 立ち絵は正面向き、動きのコマは横向きでよい

⚠**立ち絵（idle）は必ずこちらを向いて両目が見えること。** 完全な横顔は不可。
プロンプトに `same side-view stance facing right` のような横向き指定を**書かない**。

**歩行など動きのコマは横向きで正しい**（動きは横から見せるもの）。

これは同じ穴に2回落ちた項目。ぴよ氏の冒険では、旧スクリプトの identity 文に横向き指定が残っていて
魔女／侍／サイバー／忍者の4スキンが横顔で焼かれ、まとめて描き直しになった。

## bbox の整列を忘れない

コマごとに被写体の位置が数px動くと、再生時にキャラが**震えて見える**。
クロマキー後、**基準となる bbox（足元と中心）に合わせて全コマを揃えてから**書き出す。
