# 透過スプライト／アイコンの作り方

ショップの品、ドロップ品、図鑑アイコン、宝箱など、**背景を抜いて使う小さい絵**。

## ⚠ 最大の落とし穴 — Gemini は透過PNGを返さない

OpenAI の `background: 'transparent'` に相当する指定が **Gemini には無い**。
プロンプトに「Fully TRANSPARENT background」と書くと、モデルは
**「透明のつもりで市松模様を絵として描く」**。

実測（ぴよ氏の冒険 1.630）: 初回生成は**全候補が不透明100%**（四隅が `[221,221,221]` などの灰色）。
`trim()` も `fillHoles()` も効かず、32pxに縮めると白／灰の四角い板になった。

### 正しいやり方 — 抜きやすい単色背景を指定して、こちらでクロマキーする

プロンプトに入れる文:

```
The background must be a FLAT SOLID PURE GREEN (#00FF00) rectangle filling the entire canvas —
a chroma key screen. Do NOT draw a checkerboard, do NOT draw a gradient, do NOT draw any scenery.
Nothing in the object itself may be green.
```

**緑を選ぶ理由**: 石（灰）・紫の光・木箱の茶・金 のどれとも十分に離れていて、誤って抜かない。
⚠**被写体に緑が入る絵ならマゼンタなど別の色にする**（草・エメラルド・緑の服など）。

## 後処理の順序が重要

```
chromaKey() → fillHoles() → trim() → resize() → 半透明の縁を潰す
```

- **`chromaKey()` を必ず先に。** 先に穴埋めをすると背景が「外側」と判定されず、全面が不透明のまま残る
- **`fillHoles()` は縮小より前に。** 生成画像は明るい部分がくり抜かれることがあり、
  縮小後だと穴が潰れて直せない
- 最後に alpha を 0/255 の二値に落とす。半透明の縁が残ると、小さく描いたときに輪郭がぼやける

### chromaKey の判定式

```js
if (g > 90 && g > r * 1.35 && g > b * 1.35) { alpha = 0; }   // 背景＝緑が強く、赤と青の両方を明確に上回る
const rb = (r + b) / 2;                                       // スピル（縁の緑にじみ）除去
if (g > rb * 1.15) green = Math.round(rb * 1.15);
```

「緑が強い」だけでなく**赤と青の両方をはっきり上回る**という条件にしてあるので、
木箱の茶や石の灰は絶対に当たらない。

## 出力サイズは描画コードから決める

⚠**ゲーム内で横長に描くものを正方形で書き出すと、横に潰れる。**

描画コードの `drawImage(img, x, y, W, H)` を見て、**その2倍**で持つ。
2倍にしておけば等倍表示で半分に縮むだけ＝高精細のまま使える。

> 実例（ぴよ氏の冒険 1.630）: 宝箱は `LUCKY_CHEST_W/H = 52x36` なので `104x72` で出力。
> 当初 52x40 のつもりで作ったが、**生成された絵の実比が 1.443 だったのでコード側を絵に合わせた**。
> 絵を歪めるくらいなら、描画側の数字を動かすほうが良い。

## 「開いた状態」など、対になる絵の作り方

⚠**別々に生成すると色と形が必ずズレる。**

宝箱の「閉」と「開」を独立に生成したら、木目も金具も揃わなかった（ユーザー指摘）。
**1枚だけ生成し、パーツを切り出して動かす**（フタだけ切り出して倒す等）。
描画方式さえ組めば、絵は1枚で足りる。

## 実装済みの雛形

`scripts/template-gemini-sprite.mjs`（このスキルに同梱）に `chromaKey` / `fillHoles` / `toSprite` 一式が入っている。
**新規はこれを `tools/gemini-<name>.mjs` へ複製して、`ASSETS` だけ書き換える。**

ぴよ氏の冒険の実例: `tools/gemini-ug-pass-chest.mjs`

## 同じ棚に並ぶものはシルエットで区別する

アイコンは小さく表示されるので、色ではなく**輪郭**で見分けがつく必要がある。

> 実例: 地底入場パスは「地底の主の加護（丸い石像の目）」と同じ棚に並ぶので、
> **切り欠きのある札**（チケットの半券のような輪郭）にして、丸との区別を作った。

プロンプトに「so its silhouette is instantly distinct from ○○」と明示的に書くと効く。
